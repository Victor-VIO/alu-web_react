# Webpack

Learning how to set up Webpack: entry points, output, loaders, plugins, code splitting and the dev server.

- `task_0`: basic setup without a config file
- `task_1`: webpack config file, jQuery and Lodash debounce
- `task_2`: CSS and image loaders with image optimization
- `task_3`: dev server, multiple entry points, HtmlWebpackPlugin, source maps and chunk splitting
