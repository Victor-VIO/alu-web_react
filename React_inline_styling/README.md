# React inline styling

Holberton dashboard restyled with inline styles and [Aphrodite](https://github.com/Khan/aphrodite):

- `task_0`: inline row colors in `CourseListRow`
- `task_1`: CSS files replaced by Aphrodite styles
- `task_2`: conditional Aphrodite styles for notifications and course rows
- `task_3`: responsive layout under 900px with media queries
- `task_4`: hover animations (opacity + bounce) on the notifications menu item

Each task lives in `task_N/dashboard`: `npm install`, `npm test`, `npm run build`, `npm start`.
